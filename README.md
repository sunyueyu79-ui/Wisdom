# Wisdom 资料书架

无需数据库、无需构建服务器的静态资料馆。GitHub Pages 从 `main` 分支根目录部署。

- 首页：`/Wisdom/`
- 李录访谈：`/Wisdom/articles/li-lu-2026/`
- 资料清单：`catalog.json`
- 首页模板：`templates/library.html`
- 首页生成器：`scripts/build-library.mjs`

## 添加资料

1. 在 `articles/<稳定英文标识>/index.html` 添加阅读页，使用唯一 `data-article-id`。共享资源路径从该目录使用 `../../`。
2. 核对全文、出处与导读；为该资料配置朗读、金句署名及对应章节二维码，不要沿用其他资料的卡片出处。
3. 向 `catalog.json` 添加标题、人物、日期、主题、简介、页数、来源说明和独立路径。
4. 在仓库根目录运行 `node scripts/build-library.mjs`。生成器会检查资料路径和重复标识。
5. 连同生成的 `index.html` 提交，GitHub Pages 自动发布。

## 兼容与进度

旧首页的 `?v=1` 至 `?v=9` 链接，以及 `#p…`、`#text-…`、`#reading`、`#guide`、`#sources` 等旧锚点，自动跳到李录访谈并保留定位。无参数的旧首页链接现在打开书架，第一份资料可直接进入。

阅读与听读进度使用 `wisdom-article-<id>-v1` 分开保存。李录旧的 `wisdom-li-lu-v1` 记录会自动迁移；字号与主题仍在同一浏览器的所有资料间共享。阅读与听读进度不上传云端；个人金句收藏通过 Supabase 登录后同步。

Cloudflare Web Analytics 已保留在首页和阅读页。资料内容与相关权利归原权利人，网页内提供出处说明。

## Umami 操作事件

网站统计 ID：`f3d5299c-e0b0-4dd5-91df-45820caabed7`。这是公开的前端配置，并非管理 API 密钥。

首页和阅读页都已接入 Umami；Cloudflare 继续保留。`analytics-events.js` 为失败隔离的事件接口，脚本尚在加载时最多暂存 40 个事件、等待 15 秒，不影响阅读功能。

- 全文搜索：提交、选择建议词或停止输入约 1 秒后记录；同一关键词的重复渲染不重复计数，不上传搜索词。
- 搜索结果跳转：记录原文页码。
- 朗读开始、暂停、继续、停止：按用户操作计数，不按朗读短句计数。
- 金句生成：卡片实际生成后记录；不上传金句正文。
- 金句保存点击：表示点击保存入口，不代表设备已完成文件保存；长按图片保存无法可靠统计。
- 金句分享发起、完成、取消、失败：完成仅表示系统分享 API 返回成功，不代表微信收件人已收到。
- 链接复制成功、资料打开、书架搜索、主题筛选。

事件属性只传资料标识、页码、入口和结果数量等少量信息，不设置个人身份标识，不启用录屏。

## 个人金句收藏

首页和阅读页的“登录 · 收藏”入口使用 Supabase Email Auth。金句卡片可收藏当前文字和原文页码；我的收藏支持分页、返回原文和移除。相同账号的多设备可通过打开或刷新收藏列表同步。图片仍由设备端生成。配置和验收步骤见 `supabase/README.md`。

## 外部原文链接

目录条目可设置 `format: "external"`，`path` 为 HTTPS 原文网址，`pages: 0` 表示未在站内收录分页全文。书架标注来源并在新标签打开，不显示站内进度或虚构页数。2024 年李录北大光华演讲以此方式收录。
